Typography scale

The UI is set in DM Sans. The base UI size is small (--fs-ui: 0.75rem = 12px), which is the single biggest accessibility risk in the system — see findings.

12px base is dense but fully zoomable to 200%

WCAG has no hard minimum font size. The 12px (--fs-ui) and 11px (--fs-label) labels stay legible because their text colors now carry AAA-level contrast (≥7:1, see findings 1–2), and the text-scale control (--wise-text-scale) plus browser zoom both reach 200% without clipping — satisfying SC 1.4.4.

Spacing & radius scale

Radii tokens drive every card, pill and module. Spacing is applied ad-hoc (4 / 8 / 12 / 14 / 18 / 28 / 32px) rather than via named tokens.
