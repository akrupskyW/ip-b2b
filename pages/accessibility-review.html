text_fieldsTypography scale

The UI is set in DM Sans. The base UI size is small (--fs-ui: 0.75rem = 12px), which is the single biggest accessibility risk in the system — see findings.

warning
12px base body text is below comfortable reading size

WCAG has no hard minimum font size, but 12px (--fs-ui) and 11px (--fs-label) labels are dense. They pass only because the text colors carry high contrast. The text-scale control (--wise-text-scale) and browser zoom must keep working up to 200% (SC 1.4.4) without clipping.

Generated audit of the WISE design tokens (pages/agent-page.css, pages/portfolio.css, pages/scout-chat.css). Contrast ratios use the WCAG 2.1 relative-luminance algorithm and are recomputed on every theme switch. Translucent tokens (rgba borders, soft tints) are alpha-composited over their resolved background before measuring. This is an automated review and complements, but does not replace, testing with assistive technology and real users.
